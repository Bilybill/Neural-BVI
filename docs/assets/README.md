# README visual assets

The README reproduces three paper figures. The PNGs are direct renders of the figure PDFs; scientific data, labels and panel layouts are unchanged.

| Asset | Paper source | Transformation |
| --- | --- | --- |
| `paper/architecture.png` | Figure 1: method framework | PNG render, longest edge 2400 px |
| `paper/synthetic-results.png` | Figure 2: synthetic reconstruction | PNG render, longest edge 2400 px |
| `paper/field-results.png` | Figure 3: field-data comparison | PNG render, longest edge 2400 px |
| `brand/neural-bvi-logo.png` | AI-generated project identity | Decorative branding |

The synthetic example is model `model_924.mat` (global index 923), view `mixed_5db`, from the released test set. The field image is a paper visualization; the underlying recording is not distributed.

`assets.json` records image SHA-256 checksums. The logo was generated with an AI image tool and was not used to produce scientific figures or experimental evidence.
