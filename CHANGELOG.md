# Changelog

## 0.1.0 — local release candidate

- Installable package and CPU-first procedural training/inference demo.
- Preserved research dependency closure with source/export hashes.
- Frozen six-method final evaluation settings, calibration assets and archived metrics.
- Explicit data/checkpoint availability and development/holdout history.
- Regression tests, source checks, CI, contributor guidance and deterministic source packaging.
- Apache-2.0 license, project attribution and license metadata in source and package distributions.

This packaging release does not retrain the paper networks or change archived numerical results. Remote CI validation is tracked on GitHub before tagging a release.
